# Security policy

## Supported version
The current release candidate / latest main is the supported line.

## Reporting
For security-sensitive reports, avoid posting secrets, credentials, tokens, private save exports, or personal data in a public issue.

For normal game bugs, use the repository issue templates.

## Project data policy
The games are designed to run primarily in-browser. The shared local telemetry baseline stores aggregate session/action/time counters in localStorage only and does not transmit them.

Any future remote analytics or account system must be reviewed separately for privacy, consent, data minimization, retention, and deletion behavior.
