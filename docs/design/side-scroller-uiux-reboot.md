# 剣戟の森 — UI/UX Reboot 実装設計

## 目的

コンセプトアートの迫力を維持しながら、実際に操作できるゲーム画面として成立させる。
静止画の再現ではなく、`予兆を見る → 避ける/間合いを取る → 斬る → 反応を見る → 次の判断` が一目で理解できる画面を Source of Truth とする。

## 画面の一文

**敵の予兆を見て、避けて、斬り返し、BOSSを倒す。**

## 優先順位

1. 戦闘フィールド
2. 主人公 / 敵 / BOSS
3. 攻撃・回避判断
4. HP / BOSS HP / WAVE
5. COMBO / 奥義
6. 装備・補助情報

ゲーム中の説明文・装備詳細・サブメニューは主戦闘画面から外す。

## Landscape 800×450 — Primary

```text
┌────────────────────────────────────────────┐
│ [顔] HP/奥義     WAVE / STAGE       BOSS HP │  HUD 12〜14%
├────────────────────────────────────────────┤
│                                            │
│ HERO →→  SLASH / HIT  →  ENEMY → HUGE BOSS │
│                                            │  FIELD 65〜70%
│      COMBO             DODGE / CHANCE      │
│        森の前景・中景・遠景 / parallax       │
│                                            │
├────────────────────────────────────────────┤
│ [← ↑ → ↓]                    [技][跳][斬][奥義] │ CONTROL 18〜22%
└────────────────────────────────────────────┘
```

### 制約

- 戦闘フィールドは画面高の 65% 以上を維持する。
- BOSS は通常敵の見た目 1.8〜2.3 倍を目標とする。物理判定は既存のままでよい。
- 左側は移動、右側はアクションで分離する。
- 主攻撃 `斬` を最大ボタンにする。
- `奥義` はゲージ満タン時だけ強く発光する。
- HUD は上端に薄く置き、中央へカードを置かない。

## Portrait 450×800 — Fallback

```text
┌────────────────────────┐
│ HP / WAVE / BOSS / 奥義  │ 12%
├────────────────────────┤
│                        │
│   横方向の戦闘フィールド  │
│ HERO → ENEMY → BOSS     │ 55〜58%
│                        │
├────────────────────────┤
│ COMBO / 目標 / CHANCE    │ 8%
├────────────────────────┤
│ [← ↑ → ↓]      [跳][技]  │
│                 [斬][奥義] │ 22〜25%
└────────────────────────┘
```

Portrait は横持ち版の縮小ではなく、操作帯を下部へ固定する。

## BOSS UX

### Tell

- 橙〜赤の外周
- `DODGE` を短時間表示
- 攻撃方向の予兆を見せる

### Charge

- 画面速度線
- 小さな camera shake
- BOSS の発光を最大化

### Recover

- 青白い外周
- `CHANCE` 表示
- プレイヤーへ攻撃機会を明示

## 入力

### 左手

- ← / → : 移動
- ↑ : ジャンプ
- ↓ : しゃがみ / コマンド入力

### 右手

- 斬 : 通常攻撃（最重要）
- 技 : スキル
- 守 : ガード
- 奥義 : タッチ端末用の直接発動導線。ゲージ/解放条件そのものは既存ロジックを使用する。

## HUD

Landscape:

- 左上: HP + 奥義ゲージ
- 中央上: WAVE
- 右上: 通常時は残敵、BOSS時は BOSS HP + phase
- COMBO は戦場内へ出すが、常時カード化しない

Portrait:

- 上段を 90〜105px 以内
- BOSS HP は主HUD直下
- 下部 190〜210px を操作帯として確保

## 表示レイヤー

```text
背景
→ 地形
→ キャラ / 敵
→ 斬撃 / hit FX
→ BOSS key art / phase FX
→ compact combat HUD
→ touch controls
→ modal / result
```

旧コンセプトHUDと新モバイルHUDを同時表示しない。

## 既存ゲームロジックの扱い

変更しない:

- HP / damage
- wave composition
- BOSS AI
- collision
- weapon stats
- combo calculation
- Ougi / Hiougi condition
- save data

変更する:

- 情報の見せ方
- タッチ操作の配置
- スマホでの奥義導線
- HUDの密度
- BOSSの視覚的優先度

## 完成判定

- 初見 3 秒以内に主人公・敵・BOSS・攻撃ボタンが認識できる。
- Landscape で戦闘フィールドが最も大きい。
- UIカードが戦場を分断していない。
- BOSS Tell / Charge / Recover が文字を読まなくても区別できる。
- スマホで通常攻撃・移動・ジャンプ・スキル・ガード・奥義に到達できる。
- Portrait / Landscape の両方で主要タップ領域が 44px 以上。
- コンセプトアートと並べた時、同じゲームに見える。
