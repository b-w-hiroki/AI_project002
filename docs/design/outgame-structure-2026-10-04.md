# 6タイトル アウトゲーム整理案 — 2026-10-04

## 情報密度と主操作の基準

- 1画面に情報を詰め込まず、画面ごとの主目的と主操作を最初に読めるまとまりとして置く。文字を小さくして収めない。
- 補足や詳細は、必要時に専用画面・タブ・展開表示で見せる。常時表示は、その場の判断に必要な情報へ絞る。
- 段落・行間・カード内余白と操作群どうしの間隔を確保する。ただし意味のない大空白や、主操作を初期画面外へ追い出す配置は避ける。
- 管理画面のような説明カードを増やさず、既存の背景・キャラクター・装備・エフェクトを画面の主役にする。目的と主操作の文言は短くする。
- 選択状態、押下、成功、報酬獲得の反応で次の行動を理解できるようにする。普段はすっきり見せ、重要な瞬間だけ色・大きさ・動き・音の強弱を付ける。
- 各タイトル固有の色・素材・操作感を維持し、共通管理UIへ寄せすぎない。演出を追加する場合も reduced-motion では静的な状態差へ置き換え、読みやすさと余白を損なわない。

## 目的と今回の範囲

各タイトルについて、現在コードに存在するアウトゲーム機能を起点に、
「プレイ前の選択 → 一回遊ぶ → 成果 → 次の目標」を短くつなぐ。

この文書は設計のみであり、新しい育成、通貨、ショップ、価格、課金、デイリー機能は実装しない。
全タイトルを同じホーム構造へ揃えるのではなく、各ゲームで既に意味を持つ選択と報酬を優先する。

## 共通方針

- 初回または標準プレイはホームから2タップ以内、保存済みランの再開は1タップを目標にする。
- 編成・装備など任意の準備をしても、プレイ開始まで3タップ程度に収める。
- 結果画面には「成果」「保存された変化」「次の一手」を同じ視野内に置く。
- 主要CTAは実表示44px以上。戻る、途中離脱、再開の入口を主CTAと競合させない。
- ブラウザ戻るは、まずモーダルや副画面を閉じる。ラン中の誤操作で進捗を消さない。
- 新しい通貨は追加しない。既存の報酬で説明できない機能は承認まで保留する。
- デイリー、スタミナ、汎用ショップ、共通バトルパスは現段階では不要。

## 三国ポチポチ

### 既存機能

- ホーム／モード: 戦略地図・遠征、編成、武将一覧、ガチャ、装備合成、任務、闘技。
- プレイ前: 所有武将から最大3人の部隊を編成し、装備を割り当て、地域／遠征先を選ぶ。
- 成長・収集: 武将所持数、装備レアリティ在庫、装備割当、訓練、地域クリア、功績。
- 報酬: 銭、装備、武将、功績、最高遠征距離。
- 保存: 銭、最高距離、装備在庫、所有武将、装備割当、部隊、進行中遠征、地域攻略。

### 最小構成案

1. ホーム最上段を、進行中なら「遠征を続ける」、未開始なら「戦略地図・遠征へ」にする。
2. その直下に今回の部隊3人、総兵力、次ノードの勝率・持ち帰り見込みを一行で示す。
3. 編成・装備は主CTA横の「準備を見直す」から任意で入る。
4. 遠征結果では、持ち帰った銭・装備・地域進捗と「続ける／拠点へ」を同じカードに置く。

### 一周の流れ

`続きから／地域選択 → 部隊確認 → 遠征1ノード → 戦果とリスク確認 → 続行または拠点で編成更新`

### 今は不要

- 既存の銭・功績・装備以外の通貨。
- 武将ごとの別レベル、日課、追加ショップ。
- 進行中遠征を破棄させるだけの新しいホーム階層。

### 優先画面・実装順

1. ホームの「続きから」と現在部隊サマリー。
2. ノード選択前のリスク／報酬表示。
3. 結果カードから続行・拠点・編成への分岐。

### Done条件

- 保存済み遠征を1タップで再開できる。
- 新規遠征は地域選択を含め2タップ程度で開始できる。
- 離脱後も直前ノード、部隊、戦利品状態が復元される。
- 結果で「何を得たか」「次に何を変えるか」が一画面で分かる。

## Potion Workshop

### 既存機能

- ホーム: 工房画面が調合・依頼・強化・設備・転生の中心。
- プレイ前: 街の需要を見て調合、設備購入、クリック強化、依頼納品を選ぶ。
- 成長・収集: 調合力、8種の生産設備、評判、街、エッセンス、転生回数、実績、オフライン上限。
- 報酬: ポーション、評判、エッセンス、街ごとの需要倍率と依頼倍率。
- 保存: GameState全体と保存時刻。復帰時に上限付きオフライン進行を適用。

### 最小構成案

追加のホームは作らない。工房の上から順に、次の三つだけを明瞭にする。

1. 今いる街と需要対象。
2. 今日の依頼と不足量。
3. 次に買える／目指す強化。

転生可能時だけ「次の街」を強いCTAとして出し、通常時の調合CTAとは同時に競わせない。

### 一周の流れ

`街の需要確認 → 調合／設備購入 → 依頼納品 → 評判・生産増加 → 次の設備または街を目標化`

### 今は不要

- 工房とは別のロビー、汎用アイテム倉庫、別通貨ショップ。
- デイリー依頼。現行の「本日の依頼」はセッション目標として扱い、実時間更新はまだ導入しない。
- 既存エッセンス以外の転生通貨。

### 優先画面・実装順

1. 工房HUDの街・需要・依頼・次強化の配置整理。
2. 依頼納品時の成果フィードバックと次依頼。
3. 転生前の失うもの／残るもの／次の街効果の確認。

### Done条件

- 復帰後5秒以内に次の2〜5分目標を判断できる。
- 調合、依頼、強化の主対象が重ならず、44px以上で操作できる。
- 戻る／再読み込み後も購入・依頼・街・オフライン進行が復元される。
- 転生確認でリセット対象と永続対象を読み違えない。

## Karma Quest

### 既存機能

- ホーム: 新しい12年の旅を開始し、最高到達年と累計評価を表示。
- プレイ前: 固定主人公で開始。ラン中にカルマ選択、遭遇選択、戦闘、神への報告を繰り返す。
- 成長・収集: ラン内能力、派閥、カルマ、年代記、神への報告内容、結末。
- 報酬: 年ごとの評価、累計評価、最高到達年、最終年代記。
- 保存: 現状は最高到達年、累計評価、音設定のみ。進行中の12年旅は保存されない。

### 最小構成案

通貨やショップを増やさず、「旅の記録」をアウトゲームの核にする。

1. 年次報告の確定直後を安全な保存境界にする。
2. タイトルに進行中データがあれば「旅を続ける」、なければ「新しい旅」を表示する。
3. 最終年代記では、今回の主要選択2〜3件、結末、次回試したい対照的な方針を示す。
4. 過去年代記の一覧は、再開保存の次段階。まず直近1件だけでもよい。

### 一周の流れ

`旅を開始／再開 → 年の選択と戦闘 → 神へ報告 → 年代記へ追記・保存 → 次年または最終結末`

### 今は不要

- 戦闘装備、キャラクターガチャ、ショップ、日次任務。
- 累計評価を消費する恒久強化。物語の選択価値を弱めるため保留。
- 年の途中のあらゆる演出フレームを保存する複雑なチェックポイント。

### 優先画面・実装順

1. 年次報告後のラン保存と「旅を続ける」。
2. タイトルの現在年・直近の選択・次の出来事サマリー。
3. 最終年代記の比較可能な要約。

### Done条件

- 年次報告後に閉じても、その次の年から再開できる。
- 「新しい旅」は進行中データを上書きする前に確認する。
- 最終画面から1タップで別方針の旅を始められる。
- 異なる選択パターンが年代記上で明確に区別できる。

## 覇拳伝

### 既存機能

- ホーム／モード: 相手の型選択、最大3人のチーム、対戦、3連戦、物語、ガチャ。
- プレイ前: 相手の構えと説明を読み、チーム先頭を決め、モードを選ぶ。
- 成長・収集: 拳石、勝利数、保存チーム、物語クリア章。ガチャ抽選は存在するが恒久所持の用途は限定的。
- 報酬: 勝敗別の拳石、勝利数、物語進捗、ガチャ結果。
- 保存: 拳石、勝利数、チーム、物語進捗、音設定。

### 最小構成案

1. ホームを「相手」「チーム」「モード」の順に読み下せる一画面とする。
2. 物語は「続きから」、3連戦は現在の連戦目的をモードCTAに併記する。
3. 結果は勝敗、獲得拳石、相手の読み違い、同条件再戦／チーム変更／物語続行を並べる。
4. ガチャの恒久所持効果を増やす前に、現行報酬の役割を整理する。

### 一周の流れ

`相手の型確認 → チーム／モード選択 → 一戦 → 勝敗と拳石 → 再戦・チーム変更・物語続行`

### 今は不要

- 拳石と別の育成通貨、装備鍛冶、デイリー対戦。
- ガチャ結果を前提にした戦力インフレ。
- 対戦開始前の多段ロビー。

### 優先画面・実装順

1. 短い縦画面の相手説明・チーム・モード配置。
2. 結果画面の再戦とチーム変更導線。
3. 物語「続きから」と章進捗表示。

### Done条件

- 標準対戦はホームから2タップ以内で開始できる。
- どの相手、先頭選手、モードで始めるかが開始前に見える。
- 結果から再戦は1タップ、チーム変更は2タップ以内。
- チームと物語進捗が再訪時に復元される。

## 剣士の森

### 既存機能

- ホーム／準備: ロードアウト画面で近接・中距離・遠距離の3スロット、基礎装備、鎧を選択。
- プレイ中選択: 武器召喚、ウェーブ間バフ、消費アイテム、スタイル判断。
- 成長・収集: 武器個体、レアリティ、強化・進化・熟練、基礎装備レベル、鎧、通貨、最高ウェーブ。
- 報酬: 武器・アイテム・通貨・最高ウェーブ更新。
- 保存: 武器在庫、3スロット、基礎装備レベル、通貨、鎧、最高ウェーブ。ラン途中状態は保存しない。

### 最小構成案

1. ロードアウトをホームとして維持し、3スロットと鎧の不足だけ警告する。
2. 「この構成で出撃」を最優先CTAにし、変更のない再挑戦は結果から直接行えるようにする。
3. GAME OVERで到達ウェーブ、ベスト、今回得た装備・通貨、次の選択を同一カードに置く。
4. 「再挑戦」と「ロードアウトへ」を分け、直接ドラッグ操作には触れない。

### 一周の流れ

`ロードアウト確認 → 出撃 → ウェーブ／ボス → 成果と記録 → 同構成再挑戦または装備変更`

### 今は不要

- ウェーブ途中の完全復元。短いランとリトライ性を優先する。
- 装備以外のキャラクターレベル、デイリー、別ショップ通貨。
- 直接ドラッグを置き換える固定方向パッド。

### 優先画面・実装順

1. GAME OVERのタッチ再挑戦と成果表示。
2. ロードアウトの3スロット要約と出撃CTA。
3. 結果から新規獲得装備を選択状態付きで確認する導線。

### Done条件

- タッチだけでGAME OVERから1タップ再挑戦できる。
- 装備変更を選んだ場合も3タップ程度で再出撃できる。
- 戻る／再読み込み後にロードアウト、所持品、通貨、最高ウェーブが復元される。
- 375×667、390×844、844×390で直接ドラッグと44px操作領域を維持する。

## Color Match

### 既存機能

- ホーム／モード: 表記モード、60秒チャレンジ、苦手練習。
- プレイ前: ひらがな等の表記を選び、通常挑戦または練習を選ぶ。
- 成長・収集: 経済や装備はなく、ベストスコア、ベストターボ、意味・色・切替の累積正答率と反応時間を記録。
- 報酬: スコア、連続正解、ターボ、成績分析、自己ベスト。
- 保存: 表記モード、ベストスコア、ベストターボ、累積パフォーマンス。

### 最小構成案

Color Matchには一般的なアウトゲーム経済を足さない。

1. ホームに前回成績と「今回のおすすめ」を一行表示する。
2. 通常挑戦と、累積成績から判定した苦手ルール練習を明確に分ける。
3. 結果で自己ベスト差、意味／色／切替の弱点、再挑戦／弱点練習を同一カードに置く。

### 一周の流れ

`表記・挑戦種別選択 → 60秒プレイ → 成績分析 → 同条件再挑戦または弱点練習`

### 今は不要

- 通貨、ショップ、装備、キャラクター育成、デイリー報酬。
- 6個別回答ボタンを別操作へ置き換えること。
- 成績と無関係な収集図鑑。

### 優先画面・実装順

1. 結果の弱点と次CTA。
2. ホームの前回成績・おすすめ練習。
3. 長期推移は十分なデータが貯まった後に検討。

### Done条件

- 通常挑戦は1タップ、表記変更を含めても2タップで開始できる。
- 結果から再挑戦または苦手練習へ1タップで進める。
- 再訪時に表記設定と成績が復元される。
- 6個別回答ボタン、日本語優先、実表示44pxを維持する。

## 推奨実装順

1. **結果から次の操作**: Sideの再挑戦、覇拳伝の再戦／編成、Colorの弱点練習。
2. **既存保存の見える化**: 三国の遠征再開、Potionの次目標、覇拳伝の物語続行。
3. **不足している保存境界**: Karmaの年次報告後セーブ。
4. **準備画面の整理**: 三国の部隊要約、Sideのロードアウト要約。
5. **履歴・図鑑**: 各タイトルで意味が確認できたものだけを後続PRで追加する。

価格、課金、新規通貨、恒久強化バランスは、上記フローが実画面で成立した後に別途承認を得て設計する。
