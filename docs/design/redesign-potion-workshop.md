# Potion Workshop — 再設計 v2

## 1. North Star

**かわいい錬金術師と大釜を中心に、タップする・増える・強化する・工房が育つが1画面でつながる放置系錬金クリッカー。**

現状は経済ロジックと設備が強い一方、画面の主役が分散している。再設計では「錬金術師 + 大釜」を視覚の中心に固定し、右側の設備群は補助情報へ下げる。

## 2. 1画面で伝えること

1. 大釜をタップすれば作れる。
2. 作るほど通貨が増える。
3. 設備を買うと自動生産が増える。
4. 依頼を達成すると評判が上がる。
5. 工房が発展すると次の世界が開く。

## 3. メイン画面構成

### Top
- 工房Lv / 評判
- Potion / Essence
- 生産 / sec
- Settings

### Center-left — Hero Zone
- 錬金術師を大きく表示
- 大釜を中央下へ配置
- 大釜全体を主要タップ領域にする
- タップ時は液体発光、泡、数値、キャラ反応を連動
- `BREW ×N` は連打中のみ表示

### Right — Management Zone
上から優先順に:
1. 本日の依頼
2. おすすめ強化
3. 設備一覧への導線

設備8種を常時すべて並べない。現在買える設備 / 次目標 / 注目設備を前面に出し、詳細一覧は展開式にする。

### Bottom — Production Belt
- 生成中ポーション3〜5種
- 所持数
- 毎秒生産
- 次に解放されるポーションまたは設備
- 工房発展ゲージ

## 4. コアループ

`TAP` → Potion獲得 → Upgrade購入 → /sec上昇 → 依頼達成 → Reputation上昇 → Workshop Progress → 新設備 / 新エリア

この循環を画面上の位置関係でも左→右または中央→右→下で読めるようにする。

## 5. HUD

常時:
- Potion総量
- +/sec
- Reputation
- Workshop Progress
- Next Upgrade cost

条件表示:
- Prestige解放率
- Contract progress
- Offline gain

Footerの生涯統計は主要画面から外し、Stats/Settingsへ移動してよい。

## 6. CTA優先度

1. **大釜 TAP** — 最大
2. **今買うべきUpgrade** — 中
3. **依頼を納品** — 中
4. 設備一覧 / 転生 / データ管理 — 小

現状の複数カードが同じ強さで並ぶ状態を避ける。

## 7. 演出

### Brew
- 大釜内液体が発光
- 3〜6個の粒子
- `+Potion`
- 連打でキャラ表情 / 小さなリアクション

### Upgrade
- Before `/sec` → After `/sec`
- 設備が背景に追加される
- 重要アップグレードはカードを1回光らせる

### Contract
- 納品対象が大釜から依頼カードへ飛ぶ
- Reputation count-up

### Workshop Level Up
- 背景小物追加
- 新設備 silhouette → reveal

## 8. アート方向

- 明るい木製工房 + 水色 / 白 / 緑の魔法光
- キャラは中央主役、UIより高コントラスト
- 大釜は黒鉄だが周囲を暗くしすぎない
- 右管理UIは羊皮紙または白系カードで統一
- 強化アイコンは設備の形が分かるシルエットを優先
