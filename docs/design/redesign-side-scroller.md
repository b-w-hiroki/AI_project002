# 剣戟の森 — 再設計 v2

## 1. North Star

**敵の予兆を読み、回避し、斬り返して前へ進む横スクロールアクション。**

現状は戦闘ロジックと装備・流派・WAVEが豊富だが、情報が分散して「何を倒せば終わりか」「今どこまで進んでいるか」が弱い。再設計ではプレイフィールドを最大化し、WAVEをステージ攻略として見せる。

## 2. 1画面で伝えること

1. 主人公はどこにいるか。
2. 敵 / BOSSはどこか。
3. 何体倒せば次へ進むか。
4. COMBO / 奥義 / スキルがどれだけ溜まっているか。
5. 今の流派でどう戦うべきか。

## 3. 画面構成

### Top-left
- 主人公ポートレート
- HP
- Armor
- Weapon

### Top-center
- `STAGE 1-4` または `WAVE 4/5`
- ステージ進行バー
- 現在目標 `敵をあと3体倒せ`

### Top-right
- Pause
- 3つまでのサブミッション
- BOSS時はミッションを畳み、BOSS HPへ切替

### Center
- プレイフィールドを画面の65〜75%確保
- 主人公は現在より視認しやすい大きさを維持または微増
- 通常敵は小さく、BOSSは明確に大きくする

### Bottom-left
- 仮想スティック

### Bottom-right
- Attack
- Skill
- Jump
- Ougi
- 武器切替は小さく補助配置

## 4. ステージ構造

既存WAVEロジックを内部で残しながら、見せ方は以下へ寄せる。

`Stage Start` → `通常WAVE` → `強敵WAVE` → `BOSS` → `Result`

1ステージ3〜5WAVE程度を基本とし、BOSS到達を短期目標にする。

無限生存モードは別モードとして残してもよいが、初見導線は「終点のある冒険」を優先する。

## 5. ボス読み合い

既存の `tell → charge → recover` をゲームの顔にする。

### Tell
- BOSSの進行方向を矢印 / 赤帯で表示
- `DODGE!` の短い警告
- 音で予兆

### Charge
- カメラシェイク
- 速度線
- 攻撃判定を読みやすくする

### Recover
- BOSSを一時的に発光 / 低姿勢
- `CHANCE!`
- 与ダメージ倍率をHUDで伝える

## 6. COMBO / 流派

### 連撃
- COMBOを大きく右上または左中央に表示
- 10 / 30到達で見た目を変える

### 居合
- 溜め状態を円形ゲージまたは刀身光で表示
- 「今撃つと強い」が分かることを優先

流派説明文を常時表示しない。状態をアイコンと短い文言で示す。

## 7. 報酬と成長

WAVE終了時:
- 武器 / Armor / Buff候補を1〜3個提示
- その場で変化が見える

Stage Clear:
- SCORE
- Best Combo
- Damage Taken
- 獲得アイテム
- 次ステージ解放

## 8. アート方向

- 明るいファンタジー森 + 青空 + 奥行きのある遠景
- 主人公の攻撃軌跡は水色〜白
- BOSS警告のみ赤 / 橙で強く対比
- 通常敵はシンプルに統一、BOSSはシルエットから差を付ける
