# 三国ポチポチ — 再設計 v2

## 1. North Star

**武将を集め、編成し、戦略マップを進軍して天下統一へ向かう「見て分かる」三国遠征ゲーム。**

現状の遠征ロジックは活かしつつ、画面の主役を「遠征中の一場面」から「章マップと出陣判断」へ広げる。プレイヤーは、どこへ進み、誰を連れて行き、何を得るかを出陣前に理解できる。

## 2. 1画面で伝えること

1. 今どの章にいるか。
2. 次に攻める戦地はどこか。
3. 編成中の武将は誰か。
4. 勝率 / 危険 / 報酬はどれくらいか。
5. 出陣すると何が進むか。

## 3. メイン画面構成

### Top
- 主君Lvまたは進行章
- 銭 / 功績 / スタミナ相当
- 設定

### Left — Mode Navigation
- 遠征
- 武将
- 編成
- 任務
- 商店

通知がある項目だけ赤点を付ける。常時5個以上に増やさない。

### Center — Campaign Map
- 現在章を最大表示
- 戦地ノードを3〜6個
- クリア済 / 次 / ロックを明確に区別
- ボス・関門を通常ノードより大きく
- 道筋は一本の線ではなく、地域の地形に沿って視認できるルートにする

### Bottom — Expedition Dock
- 編成3人
- 戦力
- 勝率
- クリア報酬
- 大きな「出陣」CTA

## 4. ゲームループ

`武将獲得` → `編成` → `戦地選択` → `出陣` → `進軍 / 分岐` → `関門戦` → `報酬` → `次章解放`

既存の「途中帰還」「敗走時半額」「街道 / 山道」の判断は、章マップの中に残す。

## 5. 進軍画面

進軍中は別画面または同一画面のフォーカス状態にする。

常時表示:
- 現在地点 `6/10`
- 兵力
- 持帰り予定
- 敗走時確保額
- 次戦勝率
- 現在ルート

中央:
- 味方隊列
- 敵 / 関門
- 背景の移動

下:
- `進軍する`
- 分岐時のみ `街道 / 山道`
- `帰還して○銭を確保`

## 6. 報酬設計の見せ方

出陣前:
- 初回踏破報酬
- Rare装備
- 功績
- 基礎収穫倍率

進軍中:
- 今持って帰れる額
- 次地点で増える期待値

クリア時:
- 獲得銭
- 功績
- 装備
- 次章 / 地域解放

数値だけでなく、報酬アイコンを並べる。

## 7. 武将の見せ方

- 編成3人は常に顔が読めるポートレートで表示
- 役割（猛将 / 守将 / 軍師 / 商才）は小タグ化
- ATKだけでなく「この遠征で効く効果」を短文表示
- 主将を1人、大きく見せる

## 8. アート方向

- 夕景・戦火・山河・城壁を使った重厚な三国志感
- UIは黒鉄 / 漆 / 朱 / 金
- 地図は羊皮紙より「戦地を俯瞰した絵巻・軍略図」寄り
- ロック地域は彩度を落とし、攻略済は旗・印で状態表示

## 9. 必須アセット

P0:
- 地域別戦略マップ 3面
- 戦地ノード / 関門ノード
- 武将ポートレート統一
- 報酬アイコン（銭 / 功績 / 装備）

P1:
- 出陣演出用旗 / 印
- 地域ボス差分
- 章タイトル演出

## 10. 現状との差分

活かす:
- 3地域
- 鍛錬
- 3人編成
- 役割効果
- 街道 / 山道
- 遠征保存
- 関門演出

変える:
- `camp` が情報カード中心になっている構造
- 遠征開始前に報酬と目的が弱い点
- 戦略マップのサイズと主役度
- 武将の顔が小さい点
