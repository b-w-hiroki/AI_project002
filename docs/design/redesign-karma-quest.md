# カルマクエスト — 再設計 v2

## 1. North Star

**小さな選択が勇者の能力・派閥評価・語られる伝説を変える、勇者育成 × 選択RPG。**

現状は選択・討伐・神への報告という独自性が強い一方、画面が説明中心になりやすい。再設計では、主人公と世界を大きく見せ、その上で「今の選択がどこへ効くか」を一目で理解できるようにする。

## 2. 1画面で伝えること

1. 今何年目 / どの季節か。
2. 主人公が今どんな人物になっているか。
3. 誰から何を頼まれているか。
4. 選択すると何が動くか。
5. その積み重ねがどんな伝説に向かっているか。

## 3. メイン画面構成

### Top
- YEAR / Season
- Evaluation
- Currency / resource
- Current title or blessing

### Left
- Quest
- Allies
- Items
- Chronicle

### Center
- 主人公の立ち絵
- 背景世界（王都 / 村 / 荒野など）
- NPCとの会話

### Right
- Karma軸
- 勢力評価
- 神託 / Mandate

### Bottom
- 2〜3個の選択肢
- 選択ごとに影響先を短く表示

例:
- 村を助ける `王国 + / 慈愛 +`
- 見て見ぬふり `変化小`
- 魔物を利用 `魔族 + / 混沌 +`

## 4. 選択の見せ方

文章量を減らし、以下の順で読む。

1. **誰が困っているか**
2. **何が起きているか**
3. **どうするか**
4. **何が動くか**

選択後は即座に:
- 該当勢力バーが動く
- Karma markerが動く
- 主人公のステータス変化を小さく表示
- Chronicleへ一行追加

## 5. 勇者育成

現状のKarma → Stats変換を視覚化する。

常時全能力を見せず、主人公の横に4項目を簡潔に表示:
- ATK
- DEF
- HP
- MAGIC

Dominant Factionに応じて:
- 紋章
- オーラ
- 装備の色
- 立ち姿

のどれかを段階的に変える。

## 6. 神への報告

年末のReportは通常画面とは別の儀式画面にする。

- 年代記から2場面を選択
- 軍神 / 慈愛神の価値観を表示
- 選んだ場面の評価を予測
- 提出後にBlessing / Threat / Next Mandateを提示

「何を報告するか」が次年を変えることを大きく見せる。

## 7. Chronicle

Chronicleはログではなく、プレイヤーの物語の成果物にする。

- 年ごとに1〜2行
- 重要イベントにアイコン
- 最後に称号へ集約
- 可能なら最終結果を1枚画像として保存できる形を将来検討

## 8. アート方向

- 王道ファンタジー + 古書 / 羊皮紙
- 世界背景は明るく広く、UIは濃緑 / 金 / 羊皮紙
- 主人公は中央に大きく配置
- Karmaは善悪二元論ではなく、複数勢力と神託の重なりとして見せる

P0:
