# モック寄せの実装計画と判断基準

基準は写真5。450×800の縦画面と800×450の横画面を別構図とし、描画全体は同率縮小する。主役は街と人物、紙面は出来事を読む場所、青赤は操作の場所とする。

| 対象 | 今回の実装 | 維持する条件 |
| --- | --- | --- |
| 王都 | 背面主人公を最大480×634、中心150,565へ。街を残しながら手前の存在感を増す | HUD・左ナビ・依頼カードの操作位置は維持。本文への重なりを目視 |
| 会話 | 紙面中心290,168・304×174、下端から依頼者側へ紙の尾。見出しは紙上の暗い文字と細い罫線 | 本文22px、幅264、中心290,193。顔は紙面より下、主人公は左下のバストアップ |
| 横会話 | 紙上の見出しと罫線に統一。人物は左、依頼と操作は右 | 既存の人物領域と操作領域を維持 |
| 選択肢 | 主ラベル左に天秤／王冠。主ラベル中心を12px右へ、幅276px、26px | 補足19pxと操作領域382×80を維持。意味は文言も併記 |
| 結果 | 肖像中心だった魔石・護衛・酒代の承諾3場面を、行動と成果が分かる環境絵へ置換 | 8依頼×2結果を点検。拒否・他の承諾は物語が成立している素材を維持 |
| 年代記 | 挿絵148×154・左38,上140へ拡大。本文幅200・中心304,244、左揃え | 出来事→直前記録→街→能力→再出発の順を維持 |
| 質感 | 前工程の細い金具・紙・青赤ボタンを継承 | 全面発光、追加の入れ子枠、伸ばした素材を避ける |

人物4派閥の顔の方向・大きさ・光源を比較する。人物専用素材は既存の共通領域を維持し、意味のない拡大や色変更はしない。新しい場面絵は暖かい光、象牙色の街、青い旗で統一する。

合格条件: 最小320×568で本文・顔・CTAが衝突しない。長い依頼・16結果・年代記・横画面・回転・読込中を確認。UIテスト合格と主観的なモック一致は区別する。実iPhone確認はWi-Fi接続が可能になるまで保留。
