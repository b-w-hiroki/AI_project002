# Karma Quest 画面設計図

正式モックの4画面を、縦450×800の設計座標へ固定する。目的は、実装を進めても人物、本文、カード、CTAが互いに重ならない状態を維持すること。スマホではCanvas全体を同一倍率で縮小し、内部座標は変更しない。

## 共通境界

| 領域 | 座標・寸法 | 規則 |
| --- | --- | --- |
| 設計Canvas | `0,0,450,800` | 縦横別に引き延ばさない |
| 装飾枠 | `5,5,440,790` | 入力・本文を置かない |
| コンテンツ安全域 | `8,8,434,784` | 主要情報と操作は原則この内側 |
| 最小外周余白 | 8設計px | スマホCSS外周は6px、Safe Areaを別途加算 |
| 人物と文字 | 16設計px以上 | 顔の矩形へ見出し・本文を重ねない |
| カード同士 | 8設計px以上 | 金枠を共有・接触させない |
| カードとCTA | 16設計px以上 | CTAの押下範囲をカードから分離 |
| 通常タップ | 実表示44 CSS px以上 | 透明Zoneも同じ基準 |
| 主要CTA | 実表示52 CSS px以上 | 320×568でも維持 |

描画順は `背景 → 場面絵 → 人物 → 情報カード → CTA → 外周枠 → 入力Zone`。入力Zoneは対応する表示面と同じ外接矩形に限定し、別の操作領域へ侵入させない。

## 1. 王都ホーム

| 部品 | 座標・寸法 | 重なり条件 |
| --- | --- | --- |
| HUD | `15,11,420,64` | 主コピーはHUD下端から8px以上離す |
| 左メニュー | `12,104,54,354` | 主コピー・人物はx=74より右を基本とする |
| 主コピー | 中心`260,140`、幅350 | 勇者の顔と8px以上離す |
| 背面勇者 | 中心`232,505`、最大`390×520` | 下部は依頼通知の背後で切る。カード本文へ出さない |
| 新規依頼通知 | 中心`166,590`、`274×38` | 依頼カードへ4px重ね、同じ操作群として見せる |
| 依頼カード | 中心`225,656`、`414×112` | 肖像は`31,618,68,78`。本文開始x=130以降 |
| 下部ナビ | `8,724,434,68` | 5項目を等分。選択面以外をCTA色にしない |

ホームで許可する重なりは「勇者の下端を依頼通知の背後で切る」だけ。人物の顔、依頼本文、ナビ文字は互いに重ねない。

| 部品 | 座標・寸法 | 重なり条件 |

依頼文は最大3行を基準とする。収まらない場合は、短文化 → カード本文領域の拡張 → 詳細の段階表示で解決し、20設計pxから縮小しない。

| 部品 | 座標・寸法 | 重なり条件 |

| 未解放カード | 中心`225,355`、`388×98` | 出来事カードと10px以上離す |

| 街名帯 | 中心`225,492`、`382×54` | 街画像下部へ重ねる。文字は中央安全域内 |

| 再出発CTA | 中心`225,708`、`360×72` | 成長欄下端から16px以上確保 |

年代記は上から「出来事 → 未解放 → 場所 → 主人公 → 操作」の順で読む。各面の金枠を接触させず、装飾より本文と人物を優先する。

## スマホ検証

最低限、`320×568`、`360×640`、`375×667`、`390×844`、`430×932`で確認する。Canvasの縦横比、画面内収まり、主要CTAの実表示52px以上、人物の顔と本文の非重複、タップ座標を検証する。横画面は別の800×450設計図を用意し、縦画面を回転・縮小して流用しない。
