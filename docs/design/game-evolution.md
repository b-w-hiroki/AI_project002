# ゲーム性 × ビジュアル 統合設計

2026-09-06 / AI_project002 / 初回実装仕様

追補：三国ポチポチの三地域攻略・鍛錬・戦略地図は、次の優先改修で実装済み。[第二段階の設計](sangoku-campaign.md)を最新仕様として参照。以下の表は初回の境界を記録したもの。

## 目的

既存6作品に、プレイヤーが「次はこうしてみる」と考える選択を作る。数字・ボタン・素材の追加ではなく、判断→結果→見た目の変化を一続きにする。既存のゲーム・セーブを活かし、追加生成素材なしでも遊べる縦切りの改修を行う。

## 三国ポチポチ：遠征設計

- 出発前に所持武将から1〜3人を選ぶ。初回に蒼刃・小兵・足軽を保証し、ガチャなしでも編成可能。既存所持数を上書きしない。
- 猛将：攻撃係数、守将：損耗軽減、軍師：危険な道の勝率補正、商才：収穫倍率。人数に応じて効果が重なるが上限を置く。
- 装備を含むATKを遠征戦力に使う。出発時の編成と戦力は遠征終了まで固定。
- 10地点、3・7地点後に「街道（安全）」と「山道（危険・報酬増）」の分岐。10地点目は関門戦。
- 兵力100開始。敗戦で大きく減り、勝っても少量消耗。軍師と守将の価値を異なる形で表現。
- 途中帰還は未確保コインを全額持ち帰る。兵力0で敗走し、今回の未確保コインの半分だけを持ち帰る。既存コイン・所持武将・装着装備を失わない。
- 遠征状態を保存して再読み込みから復帰。報酬は確定時に1回のみ付与。帰還結果を見てから次の遠征に進む。
- 装備は帰還距離に応じて獲得。合成は未装着の親2個を消費。同レアリティなら2個必要。既存の合成確率表を維持し、Rareは遠征踏破報酬から供給。
- UI：上部に遠征名と現在地、中央に景色と編成隊列、下部に結果・兵力・続行／帰還。帰還前に受取額と敗走時の損失を明示。

## 覇拳伝：読み合い設計

猛攻型は拳・拳・気の周期。反撃型は直前のプレイヤーの手への対抗手（初手は固定）。溜め型は蹴・気・気。次の手は今回の入力を受ける前に確定させる。予兆テキストと構え演出が一致し、敵が後出ししない。初回は予兆と相性表から正解を学べる明瞭さを優先する。

有利時のゲージ増加を大きくし、毎応酬で双方同量だった状態を改善。コマンド技は残すが、有利を取る判断と両立させる必要がある。勝敗確定を多重処理しない。予兆・敵選択・命中で戦術と見た目を結ぶ。

## カルマクエスト：伝説設計

軍神は武勇・勝利、慈愛神は支援・生還を好む。報告前に価値観と次回への影響を開示。現在の年に実際に発生した「依頼への対応」「遭遇選択」「応援」「討伐結果」からカードを作る。報告は最大2枠、選択0で提出不可。同一カードの重複採点不可。

軍神を選ぶと次の討伐が難しくなる一方、強い加護を得る。慈愛神は小さな安定した加護。翌年の育成画面で課題を確認できる。報告された場面を年代記に保存し、結末の称号へつなぐ。実際の衣装差分は未制作のため、今回の見た目の変化は紋章・称号・年代記によるものと区別する。

## ポーション工房：需要と注文

8街を3つの需要型へ対応付け、特定設備の生産を1.5倍にする。生産・オフライン進行・表示に同じ計算を使用。注文は周回中各1回だけ納品可能とし、ポーションを消費して評判を得る。評判は今周回の生産倍率を上げ、転生時にリセットされる。初期村の特典は既存経済を急変させず、街需要・評判を分けて表示する。

画面に購入設備を象徴する瓶・庭・大釜・竜を表示。全設備の絵を新規に要求せず、画像が無い設備はGraphicsで表現。注文パネルと新規説明も日英対応。

## 剣戟の森：流派とボス

既存の無限ウェーブ・ロードアウトを維持。開始時に「連撃（連続命中で追加火力）」と「居合（攻撃を控えて溜めた初撃）」を選ぶ。現在の選択と効果が戦闘HUDで読める。強化の数値と命中演出を連動させる。

ボスは静止予兆→向きを固定した突進→回復待ちを繰り返す。予兆は進行方向に描き、回避可能な情報にする。キャラ拡大・終点付きランは同時に入れず、今回の改修から切り離す。

## カラーマッチ：60秒の習熟

全体60秒と1問ごとの期限を別管理。0〜15秒は内容、15〜30秒は色、30〜45秒は5秒周期、45〜60秒は3秒周期。各問題開始時の判定を固定し、回答中のルールを変更しない。次問への切り替えを事前表示。時間切れの多重終了、遅延コールの次セッションへの混入を防ぐ。

結果は正答率・平均反応・内容／色別正答率・切替直後正答率。旧12問版とスコアを混ぜないよう60秒用キーを利用。ドラッグ操作を維持し、視覚効果がカードと回答枠を覆わない。

## 検証と受け入れ

- 変更6作品のtypecheck/lint/Vitest/build。
- 遠征は編成差・装備差・帰還・敗走・報酬一度だけ・再読み込み復帰・合成素材消費を検証。
- 覇拳伝は予兆確定、相性ゲージ、勝敗一度だけ。
- 報告は実イベント由来・2枠制限・神による評価差・次年への反映。
- 工房は旧セーブ補完・注文重複不可・資金不足・オンラインとオフライン共通倍率。
- 戦闘流派とボス周期は決定的なロジックテスト。
- 60秒は全体締切と回答締切の競合、再挑戦、記録分離。
- Chromiumでタイトル・主要プレイ・選択・結果を撮影。縦画面はスマホ幅でも確認する。実機の触感・長期バランスは別途試遊対象とする。
