# 進軍とボス戦の見せ方を分ける

2026-09-07。キャラの横並びから、景色の中で進軍し、大きな敵と対峙する構図へ。

- 上部の進行表示を75px高に圧縮。舞台をその下から542pxまで確保。
- 進軍中は背景と奥の小さな敵兵を見せ、味方を斜めに配置。
- 関門ではボスを375px高へ拡大。味方は左手前に寄せ、名前・役割は画面下の一行へ集約。
- 下部は兵力・持帰り額→勝率→主操作を順に配置。帰還は控えめなテキスト型操作とし、46px高の押せる領域を確保。
- 関門に着くと暗い幕と名前を表示し、ボスへ寄る短い演出を再生。その間の入力を禁止。
- 攻撃では味方の踏み込み・斬撃・揺れ・敵の退場と決着文字を順に見せてから報酬画面へ。
- 決着の報酬確定は演出開始時に一度だけ実施。途中で再読み込みしても報酬を失わず、同じ遠征を再精算しない。
- 新規画像やゲームの勝敗計算は追加変更しない。画像が欠けた場合も代替描画で進める。

## 検証

本作49テスト・型検査・lint・build。ブラウザで三地域攻略と登場中の入力禁止、演出終了後の操作復帰、演出中の再読み込みによる報酬保持を確認。静止画と `docs/review/sangoku-campaign/boss-cinematic.webm` を保存する。録画は実操作に一部の状態設定・固定乱数を組み合わせた検証用で、自然な一回のプレイ記録とは区別。

専用の攻撃差分イラスト、音響演出、実機での処理負荷・操作感は今後の調整対象。
