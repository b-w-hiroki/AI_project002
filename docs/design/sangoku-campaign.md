# 三国ポチポチ：三地域攻略と部隊の成長

2026-09-06 / 統合改修に続く、三国ポチポチ優先の第二段階。

追補（2026-09-07）：小兵・足軽の立ち絵と大型ボスは[キャラクター改修](sangoku-character-art.md)で制作・組み込み済み。以下の未制作記述は第二段階時点の履歴。

## 今回の到達点

「何となく遠征する」状態から、地図で次の目標を決め、収穫を持ち帰り、部隊を鍛え、次章へ進む短い攻略ループへ。ゲーム全体の完成宣言ではなく、三地域を通して遊べる攻略骨格を仕上げる。

|地域|開放条件|敵戦力への加算|収穫倍率|
|---|---|---:|---:|
|黎明の街道|最初から|0|1.0|
|翠嶺の峠|黎明の街道を踏破|65|1.4|
|紅蓮の城塞|翠嶺の峠を踏破|135|1.9|

各地域は10地点。3・7地点後に街道／山道を選択し、10地点目に関門戦。既存の編成役割・装備・勝敗計算を維持し、地域差を敵戦力と収穫に反映する。難易度は初期値であり、長期の実機試遊による調整は残る。

## 成長の報酬

- 到達3地点ごとに功績+1。帰還・敗走でも獲得し、失敗だけで終わらない。
- 各地域の初踏破で追加功績+5。通常のコイン・装備報酬とは別。
- 鍛錬は全5段階、基礎部隊戦力に1段階あたり8%を加算（最大40%）。既存の役割・装備から計算した部隊戦力に適用。
- 必要功績は順に4・6・8・10・12。鍛錬はガチャ運に依存しない成長手段。課金や新たな外部サービスは不要。
- 出発時の戦力を固定し、遠征途中の読み込みでも変化させない。
- 地域攻略・功績・鍛錬を同一のセーブ項目へ保存。同じ遠征の直後の二重報告をIDで無効化し、初踏破は地域別に記録。
- 既存コイン・装備と別キーのため、ブラウザ強制終了・容量不足を含む全報酬の原子的トランザクションは未対応。通常操作の二重精算は防止。

## 画面と視覚表現

- 戦略地図：3地域を山・川・城アイコンで接続。未開放／選択中／踏破を表示。
- 地図から現在の部隊と戦力を確認し、編成と鍛錬へアクセス。編成専用画面を分離して目的を明瞭にする。
- 背景は既存街道イラストを活かし、地域ごとに色調を変える。新規の背景イラストではない。
- 隊列を拡大・中央配置。関門が近づくと門のシルエットを表示し、ゴールを視覚化。
- 呼吸・収穫の浮き表示・大きな損耗時の小さな揺れ。画面再構築時に常時アニメーションを破棄し、蓄積を防止。
- 分岐は両ルートの次戦勝率を明示。帰還額と敗走時の回収額は従来通り表示。
- 結果に功績、次章開放、鍛錬可能状態を表示し、そのまま戦略地図へ戻れる。
- 小兵・足軽は引き続きコード描画。素材台帳の新規立ち絵は今回制作しておらず、既存の蒼刃と完全な画風統一は未達。
