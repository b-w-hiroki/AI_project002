# 覇拳伝 — 再設計 v2

## 1. North Star

**相手の癖を読み、三すくみで読み勝ち、奥義で決める短時間1対1バトル。**

現状は読み合いロジックと予兆が成立している。再設計では、画面を格闘ゲームの文法へ寄せ、2人の対峙・HP・タイマー・技入力を一目で理解できるようにする。

## 2. 1画面で伝えること

1. どちらが優勢か。
2. 相手は何を狙っていそうか。
3. 自分は何を出すべきか。
4. 奥義まであとどれくらいか。
5. ラウンドに勝つと何が得られるか。

## 3. 画面構成

### Top
- 左: Player portrait / HP
- 右: Enemy portrait / HP
- 中央: ROUND / TIME
- HP下に小さな奥義ゲージ

### Center
- 2キャラの対峙を最大化
- 中央上に短い予兆
- 読み勝ち / 読み負けはキャラの衝突位置に出す

### Bottom
- `拳` / `蹴` / `気` の3大ボタン
- 奥義ボタンはゲージ100%時に強く発光
- 相性ヘルプは初回または長押しで表示

## 4. 読み合いUI

敵の予兆は文章ではなく、3段階で伝える。

1. **姿勢 / オーラ** — 視覚
2. **短いヒント** — 「前へ詰める」「力を溜める」程度
3. **初回のみ相性補助** — `拳 > 気 > 蹴 > 拳`

正解を直接表示せず、予兆から推測する余地を残す。

## 5. ラウンド構成

推奨:
- 1試合 45〜60秒
- Best of 3 または短い連戦
- ラウンド間は2〜3秒のテンポ

現行の単戦ロジックを壊さず、まずは `ROUND 1` 表示とResult演出から導入可能。

## 6. 奥義

奥義はゲームの最大報酬。

- 読み勝ちでゲージ増加を強く見せる
- 80%以上でゲージの見た目を変える
- 100%でボタンを大きく発光
- 発動時は背景を一瞬落とし、キャラ / 技名 / ダメージを主役にする

隠しコマンドは上級者向けの秘密として残し、通常HUDでは主張させない。

## 7. Result

表示:
- WIN / LOSE / DRAW
- 読み勝ち回数
- 最大連続読み勝ち
- 奥義使用
- 豪拳石
- 次の敵 / 再戦

単に通貨を足すだけでなく、「どう勝ったか」を残す。

## 8. アート方向

- 夕暮れの闘技場 / 炎 / 旗
- Playerは赤〜橙、Enemyは青〜白など明確な対比
- HUDは黒 / 金 / 赤の格闘ゲーム系
- 通常UIは暗め、ヒット・奥義だけ強い発光

## 9. 必須アセット

P0:
- Player 通常 / 攻撃 / 被弾
- Enemy 通常 / 攻撃 / 被弾
- 拳 / 蹴 / 気 / 奥義アイコン

P1:
- 奥義カットイン
- KO / WINタイポ
- 敵タイプ別構え差分

## 10. 現状との差分

活かす:
- 三すくみ
- 敵傾向
- Tell
- Ougi
- Hidden Command
- Damage / hit effects

変える:
- 中央のキャラサイズと対峙感
- HP / Timer / Roundの格ゲー配置
- 下部入力UIの強さ
- Resultの情報量
