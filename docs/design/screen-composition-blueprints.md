# AI Project 002 — 6作品 画面構成設計図

更新日: 2026-09-13

## 0. 位置づけ

コンセプトアートを「完成時の印象・密度・世界観」のNorth Star、この文書を**実プレイ画面へ変換するレイアウト基準**とする。ゲームロジックをコンセプト絵へ無理に合わせず、主役・目的・操作・進捗・フィードバックの優先順位を合わせる。

共通レイヤー: `背景世界 → 主役/敵 → Gameplay FX → Primary HUD → Objective/Reward → Primary CTA → Alert/Result`。

原則、画面最大面積は背景世界+主役に使う。全面カードUIは禁止。主要タップ44px以上、主要CTA52px以上、Safe Area 12px以上を確保する。

# 8. 最終ビジュアルQA

各画面をスクリーンショット1枚で判定する。

- [ ] 最大面積の要素がVisual Hero
- [ ] Primary CTAが1秒以内に見つかる
- [ ] 今の目的が短文/状態だけで分かる
- [ ] 背景アートが画面の30%以上見える
- [ ] パネルが背景を不必要に覆わない
- [ ] 主要数値の位置がプレイ中に移動しない
- [ ] 成功/失敗FXが操作対象を隠さない
- [ ] 主要タップ44px以上、CTA52px以上
- [ ] Safe Areaに重要操作が侵入しない
- [ ] 縦横で情報の意味が変わらない
- [ ] コンセプトアートの密度・主役・奥行き・色を再現
- [ ] コンセプトアート内の架空UIを理由にルールを変えていない

判定: **A**=完成感と操作性が両立 / **B**=構成正しいがアート・演出不足 / **C**=UI階層または主役が設計図と異なる / **D**=何をするゲームか1秒で読めない。

以後の実装・QAは6作品すべてAを目標とする。
