## 目的と遊びの核
移動・攻撃・防御・技を使って敵と戦う横スクロールアクション。ウェーブを進み、武器育成と戦い方の選択につなげる。

## 画面と操作
ロードアウトから戦闘へ進む。移動はキーボード／画面操作、攻撃・技・防御が主要階層（ATK / SKL / GRD）。
武器は近距離・中距離・遠距離の装備枠を持ち、強化・進化・熟練度で育つ。ステージ内の召喚媒体取得でロードアウト武器へ切り替える。
戦い方は連撃／居合。連撃はコンボ、居合は間合いと攻撃間隔に応じた効果を持つ。
HUDは実際のウェーブを表示し、存在しない上限やレベルを描かない。

## 保存
武器ロードアウトと最高ウェーブは別キー。最高ウェーブは更新時だけ保存する。
進行中の戦闘を完全復元する保証はない。旧表示経路も残る。

## UI契約
ガード・攻撃・技・方向入力を素早く押し直しても、前の指離し処理が新しい押下を解除しない。最後に離した入力は従来どおり解除する。
各画面ボタンは最初に押した指を保持し、別の指の進入・離脱で解除しない。押した指が離れるかボタン外へ出ると解除する。フォーカス喪失・ゲーム領域外への離脱でも解除し、復帰後は再び押せる。

ATK / SKL / GRDを主要操作として維持する。回転後もCanvas比率・タップ位置を合わせる。
キャラクター／敵／攻撃演出の関係を保ち、背景画像を引き延ばさない。
