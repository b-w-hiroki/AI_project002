## 目的と遊びの核
派閥への選択で勇者の能力を変え、討伐の記録を神へ報告する12年の育成RPG。オンライン対人ゲームにはしない。

## 画面と操作
王都ホームの章見出しは、WebKitでも不透明な濃紺の背景を持ち、白い見出しと説明文が空のイラストに直接重ならない。
王都ホーム → 依頼の受諾／辞退 → 世界の反応（次へ） → 遭遇または討伐 → 報告 → 次の年。12年終了後は年代記 → 新しい旅。
ホームの依頼人と開始後の最初の依頼は一致する。準備中は重複開始を防ぎ、画像失敗時は再試行できる。
戦闘では声援、報告ではハイライト選択を行う。戦士・商人・荒くれ者・魔術師のカルマから能力を導く。
ホームにはキャラクター情報、リーグ、ソロレイド、音設定がある。準備中の経路を実装済み機能として案内しない。
効果音設定の読み込みが失敗した場合は既定のONで初期化する。設定の保存に失敗しても、そのセッションのON／OFF切り替えとゲーム操作は継続する。保存失敗時の設定は次回起動への保持を保証しない。正常に保存できる場合は従来どおり復元する。

## 数値と保存
- 最高到達は到達時に1〜12を保存し、次の旅で減らさない。途中の旅そのものを再開する機能ではない。
- 累計評価は非負の安全な整数。不正な加算は無視し、上限で飽和する。不正な保存値は読み込み時0、閲覧だけでは上書きしない。
- リーグは固定ライバルとのローカル比較。評価は累計評価＋最高到達×60（安全な整数上限あり）。
- レイドはHPを保存し、撃破後の受取で評価を加算して次のボスへ進む。欠損HPを撃破として扱わない。
- レイドのレベルが欠損・不正・安全な範囲外なら、HPや撃破数を引き継がず未撃破のLv.1へ復旧する。不正なレベルとHP=0の組み合わせから報酬は発生しない。
- 大きい評価点は万・億・兆の小数1桁切り捨て表示。保存値は省略しない。
- レイドのレベル・撃破数・HP・ダメージ・報酬も同じ省略表記を使用する。報酬ボタンと獲得通知を含む表示だけに適用し、戦闘計算・加算額・保存値は整数のまま維持する。

## UI契約
報告完了の待機中は記録・神様の入力を無効化し、上部案内を「報告を受け付けました」に切り替える。確定済みの内容は保持し、次の報告では入力と選択案内を復帰する。
報告確定後の次年待機中も日本語の報告画面を保持し、CTAに「報告しました」と表示する。待機中の再送信・選択変更は受け付けず、既存の500ms待機後に次の年（最終年は年代記）へ進む。
未選択の報告CTAは案内文字を半透明にせず、面を暗くして無効状態を示す。出来事を選ぶと通常の明るい面に戻る。案内の可読性を保ちながら未選択時の送信を防ぐ。
日本語の報告画面は2件選択中に「変更するには選択を外す」と案内する。1件以下へ戻すと通常の最大2件の案内へ戻る。3件目を自動で入れ替えることはせず、既存の上限を維持する。
報告の選択件数・評価点・神様の方針は縦横ともに表示し、出来事や報告先の変更に追従する。横画面でも送信前に評価点を確認できる。
日本語の報告CTAは、未選択時に「出来事を選んでください」と表示して無効にし、選択後は「1件を報告する」のように選択件数を表示する。選択解除・縦横回転後も件数と操作可能状態を一致させる。
横画面の報告先は、選択中の神様にチェック印・淡い青の背景・太い金枠を表示する。選択変更と回転後もGameSceneの報告先に一致し、色だけで選択状態を伝えない。
日本語ホームの出発カード、縦横の報告記録、横画面の報告先にも、押した指だけで確定する規則を適用する。別の指の指離し・領域外移動では確定・キャンセルしない。
共通の金枠CTAは、押し始めた指を離したときだけ確定する。別の指の押下・指離し・領域外移動はその押下を確定・解除しない。押した指が領域外へ移動した場合はキャンセルする。
縦の報告画面では神様ボタンのタップ領域を高さ64設計pxとし、320px幅のCanvas314pxでも44px相当以上を確保する。上下の余白でも選択でき、記録行や隣のボタンとは重ならない。領域外へ指を移動した場合は選択を確定しない。
日本語の縦画面の討伐は既存の勇者バストアップ・能力値・声援ボタンを大きく表示する。報告は羊皮紙の記録面で最大4件を表示し、選択した最大2件と報告先をチェック印で示す。未選択では送信できず、回転後も選択状態を保つ。
依頼画面の見出しには濃色の下地を置く。金枠の青／赤CTAはCanvasでも明るい面と暗い下端を持ち、押下中は暗くなる。押したまま領域外へ移動した場合は選択を確定しない。
共通の金枠CTAは、押下中に画面サイズが変わる・フォーカスを失う・ゲームが非表示になると押下待ちを解除する。復帰後の指離しでは確定せず、新しいタップで操作する。すでに確定して処理中の操作は取り消さない。
同じ中断キャンセルを、日本語ホームの出発カード、縦横の報告記録選択、横画面の報告先選択にも適用する。中断は選択済みの記録や報告先を変更せず、押下待ちだけを解除する。
縦450×800、横800×450の設計面。素材の縦横比を保つ。
累計評価・最高到達は設計21px（320px幅のCanvas314pxでは約14.7px）。王都名16px、最高到達パネル58px。
リーグは順位・名前・評価の3列、自分の行は色と「あなた」で示す。開いた情報・レイドは回転後も継続する。
依頼パートのプレイヤーは背中立ち絵を重ねず、既存の対話構図を維持する。

## 完了条件と非対象
初回・再読み込み・回転後に進行でき、報酬や選択が二重に確定しない。画像失敗後も再試行できる。
WebKit自動検査と実機Safari確認を区別する。クラウド保存や実対戦、途中の旅の復元は現行保証に含めない。
受入検査: [E2E](../../../games/karma-quest/e2e/game.spec.ts) の12年通し、リーグ、回転、保存復帰、画像再試行。
