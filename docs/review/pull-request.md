# ゲーム性と視覚フィードバックを6作品で進化させる（第一段階）

2026-09-07追補：関門守将・小兵・足軽の透過イラスト3点を新規生成。ボス260px/通常敵兵84pxの大きさと前後配置で役割を区別。編成・遠征・帰還・武将一覧・募集の兵士表示を統一。画像が読み込めない場合はGraphicsの代替表示を維持。ゲームロジックの変更なし。

追補：三国ポチポチの第二段階を同梱。三地域の順次開放、功績と5段階の鍛錬、戦略地図、地域色調、関門表示、帰還後の成長導線を追加。三国のテストは49件（今回14件追加）で、型検査・lint・buildと19画面の操作検証に成功。詳細は `docs/design/sangoku-campaign.md`、画像は `docs/review/sangoku-campaign/`。GitHubへの反映は書き込み権限不足で未完了。

既存6作品に、次の挑戦で変えてみたくなる選択と、その結果が見える画面を追加します。統合設計では今回の実装と今後の大規模改修を分けています。

- 三国ポチポチ：3人編成、役割・装備が効く10地点遠征、分岐、帰還／敗走、再読み込み復帰、合成素材消費、隊列と道程の表示。
- 覇拳伝：3種類の敵傾向、入力前に確定する予兆、相性によるゲージ差、構え・命中演出。
- カルマクエスト：実際の出来事を最大2枚で報告、2柱の評価と翌年への影響、称号と年代記。
- ポーション工房：街の需要、周回内の注文と評判、購入に連動する工房小物、日英の注文UI。
- 剣戟の森：2種類の流派とHUD、ボスの方向予兆・突進・隙。
- カラーマッチ：60秒の段階的ルール、切替予告、ルール別成績、旧版と独立した記録。

検証：全6作品のlint・型検査・ビルド成功、Vitest325件成功（追加23件）。Chromiumで主要画面・入力・結果を撮影し、帰還の二重精算、報告の重複提出、注文の重複、再挑戦などを確認しました。詳細と画像は `docs/review/README.md`、統合設計は `docs/design/game-evolution.md`。
