# Karma Quest ホームの進行表示更新

## 改善と実装

- 報酬受取後、縦ホームの累計評価を再読み込みなしで更新する。
- 最高到達も最新値を表示する。
- WebKitの実画面で露出した旧ヘッダーの重複描画を削除し、古い評価値と文字の重なりを除去する。
- 縦横回転、リーグ、再読み込み後の値の一致を検証する。

縦ホームだけが作成時の保存値を固定表示していた。既存のホーム更新処理で累計評価・最高到達のラベルを更新する。配置・素材・評価計算・保存処理は変更なし。PR #340上の継続作業。

## 検証

- 修正前に評価80受取後も累計評価0と表示されることを追加E2Eで再現。
- typecheck / lint / 単体79件 / build成功。
- Chromium関連4件、WebKit関連4件成功。
- 実操作で報酬受取後に評価80、最高到達7年を表示。リーグRating 500、横ホーム、縦への復帰、再読み込み後も整合することを確認。
