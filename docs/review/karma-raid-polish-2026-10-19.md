# Karma Quest 魔王戦の回転・視認性改善

## 改善リストと実装

1. 魔王戦を開いたまま回転してもHP・撃破・報酬待ち状態を維持する。
2. 直前のダメージ・報酬獲得メッセージを縦横で共有し、閉じて開き直したときは消す。
3. 閉じた画面の再出現、背後のナビへの誤入力、回転後の報酬二重加算を防ぐ。
4. 実画面で見つかったナビの前面重なりと、魔王名・結果の濃すぎる文字縁取りを修正。HP 0時に残る丸角ゲージの描画も省く。

共有するのは開閉と直前の結果だけ。HP・報酬・ダメージ計算・保存形式は既存のものを使う。両レイアウトは状態変更時に保存内容とゲージを再描画する。情報パネルと魔王戦は同時に開かない。ホームを離れると開閉状態を消す。

PR #338上の継続作業。新規画像や新しいゲーム機能は追加していない。
