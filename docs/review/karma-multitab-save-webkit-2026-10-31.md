# Karma Quest ２タブ保存 — WebKit CI 記録

PR #412 の head `0543d9f88938a3cd78b563203e294e4bafa5e9ad` に対する [WebKit Smoke](https://github.com/b-w-hiroki/AI_project002/actions/runs/41153693430/job/124395705620) では、２タブのレイド受取後に同時加算した累計評価が期待値610に対して590となり、51件成功・1件失敗した。

保存の順番待ちが２秒を超えると、既存仕様では当該タブがページ内保持に切り替わる。待機時間やその切替の記録が失敗ログになかったため、今回の原因は未確定。WindowsのローカルWebKitでは対象テストが５回成功し、診断追加後も５回成功した。再現しなかったことは解消を意味しない。

同じheadの失敗ジョブだけを再実行した２回目は成功した。初回失敗の原因はこの再実行では特定できない。

同じテストの期待値を維持したまま、各タブの加算結果、待機を含む処理時間、ページ内保持への切替有無を失敗メッセージに追加した。再発時はその記録とCI負荷、ロックの取得順を突き合わせ、タイムアウトや別の書き込み競合を切り分ける。これは報告画面のポインター所有者テストやbattle→report時間切れとは別件。
