# Karma Quest UI・素材 実装レビュー（2026-09-18）

## 今回の5項目

1. 依頼者: 戦士・商人・荒くれ者・魔術師の専用バストアップを追加。ホームの依頼カードと縦横の会話に実際の派閥を反映。
2. 統一感: 会話用の主人公を追加。主人公は左下から右、依頼者は右から左へ向き、同じ暖色光と描き込みで対話を構成。画像の縦横比は保持。
3. 装飾: 既存の濃紺・赤・金のCTA、紙面、ホームHUDを維持。年代記に開いた本の装飾を追加。新しい結果絵は見出しから顔を離すため上端を調整。
4. 横画面: ホームに案内・ワールド・仲間・図鑑・持ち物・ガチャ・ショップ・王都を配置。遭遇・戦闘・報告に800×450専用UIを実装。実装済み情報を縦横で参照し、未実装の機能はその旨を明記。
5. 通し検証: 全依頼、回転、結果の保持、人物と場面の対応、情報モーダル、報告・再出発を自動検証。通常起動から12年分をタップだけで進める検査を追加。

## 判定範囲

今回の5項目は実装・ブラウザ検証の対象。正式モックの素材・筆致を完全に複製したものではない。ユーザー指定の左下バストアップ、実ゲームの派閥・能力・履歴を優先している。

実機のノッチ・ブラウザバー・音・長時間動作は未検証。持ち物管理・ガチャ・ショップ・他5作品の追加開発、PRのマージと公開は今回の対象外。
