# Karma Quest 勇者カルマ外見ルール

更新: 2026-09-21

## 目的

カルマ傾向がステータスだけでなく、勇者の外見にも段階的に表れるようにする。
既存のモック構図と勇者の顔・体格は維持し、派閥の影響は「衣装色 / 紋章 / 光 / 小物」の順に追加する。

## 共通ルール

- 初期状態と派閥差が小さい状態はニュートラル。既存勇者アートをそのまま使う。
- 1派閥が明確に優勢になった時だけ、その派閥の外見変化を表示する。
- 顔、髪型、体格、武器の基本シルエットは共通。別人に見える変更はしない。
- 色変化だけに頼らず、専用衣装化する段階では胸章・肩・腰・武器装飾の形でも判別できるようにする。
- UIの派閥色と勇者の衣装色は同じ色相を使うが、衣装側は彩度を一段落として背景から浮きすぎないようにする。

## 戦士の派閥 — 鋼の盟約

- 基調: 深い赤 / 鋼 / 金
- 現在の簡易表現: 暖色ティント、金色オーラ、「戦」紋章
- 専用衣装化: 肩当て、胸甲、剣帯を強化
- シルエット: 肩幅をやや大きく見せる
- 演出: 直線的な光、火花、金属的なハイライト
- 強くなる能力との対応: 攻撃 / 防御

## 商人の派閥 — 繁栄の盟約

- 基調: 深緑 / 生成り / 金
- 現在の簡易表現: 黄緑寄りの衣装ティント、金色オーラ、「商」紋章
- 専用衣装化: 上質なマント、革ベルト、小型ポーチ、留め具
- シルエット: 布面積を増やし、重装ではなく裕福さを出す
- 演出: コイン状の円光、柔らかな粒子
- 強くなる能力との対応: 防御 / 体力

## 荒くれ者の派閥 — 自由の盟約

- 基調: 暗い赤紫 / 黒革 / 朱
- 現在の簡易表現: 赤紫ティント、橙赤オーラ、「荒」紋章
- 専用衣装化: 非対称の革装備、腰布、傷んだ金具、短い肩布
- シルエット: 左右非対称を強める
- 演出: 荒い火の粉、斜めの光線
- 強くなる能力との対応: 攻撃 / 一部魔力

## 魔術師の派閥 — 秘術の盟約

- 基調: 藍紫 / 淡青 / 銀
- 現在の簡易表現: 紫青ティント、水色オーラ、「魔」紋章
- 専用衣装化: 魔石、刻印布、袖や裾の文様、武器への魔法刻印
- シルエット: 肩と腰から細い布を追加し、縦方向の流れを出す
- 演出: 同心円、魔法陣、淡い浮遊粒子
- 強くなる能力との対応: 魔力

## 段階

1. Neutral — 派閥差が小さい。既存勇者アート。
2. Influence — 現在実装する段階。薄い衣装色 + オーラ + 紋章 + 称号。
3. Affinity — 将来。専用の肩・胸・腰装備差分。
4. Devotion — 将来。派閥専用の完全衣装差分。ただし顔と基本シルエットは維持。

## 現在の実装

PR #114では Influence 段階を実装する。
カルマ最大値が小さい、または派閥差が小さい場合はNeutralのまま。
ホーム、依頼会話、横画面、討伐画面で同じ判定と表現を使う。
