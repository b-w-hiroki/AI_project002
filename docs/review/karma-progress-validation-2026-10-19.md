# Karma Quest 進行記録の検証

## 改善リストと対応

1. 最高到達は0〜12の整数のみ読み込む。保存時にも同じ条件を検証し、小さな到達値で既存記録を戻さない。
2. 累計評価は非負の安全な整数のみ読み込む。不正な加算値は無視し、既存の正常な記録を維持する。安全な整数の上限では飽和させる。
3. 不正データからホーム・リーグ表示、報酬受取、再読み込み、新しい旅の記録までの復帰を検証する。

保存キーと文字列形式、報酬計算は維持。不正な保存値は読み込み時に0として扱うが、閲覧だけで元データは書き換えない。次の正規の到達・報酬で該当キーを更新する。ストレージ自体の利用禁止・容量不足への対応はこの変更には含めない。

## 検証結果

- 修正前の追加単体テストで14件の失敗を確認。ブラウザでも「最高到達99年・累計評価1.5」が表示される不具合を再現した。
- 修正後: typecheck / lint / 単体99件 / build成功。
- Chromium関連4件 / WebKit同4件成功。不正値からの復帰、既存の不正値起動、報酬即時反映、途中到達の保存を確認。
- WebKit最初の起動はChromium終了前のポート競合で開始できず、終了後の再実行は成功。アプリのテスト失敗とは区別する。
- [復帰後の320px幅ホーム](karma-progress-recovery.png)を両ブラウザで撮影・目視確認。累計評価80、最高到達0年を表示し、その後の旅開始で1年を保存。
