# Karma Quest リーグの読みやすさ

## 改善と実装

1. 一つの文章に詰めていた順位・名前・評価点を独立した列へ変更。文字サイズを20へ拡大。
2. 自分の行を淡い青と金枠で強調し、「あなた / カイト」を表示。
3. 次の順位までの点数を一覧の下へ分離。首位では専用の案内を表示。

既存の羊皮紙・金枠・青い戻るボタンを維持。評価計算、保存形式、素材は変更しない。PR #342上の継続作業。

## 検証

- typecheck / lint / 単体80件 / build成功。
- Chromium関連4件成功（リーグ、320px幅と回転、報酬後の評価、途中到達の保存）。
- WebKit同4件成功。
- 列間・行間の非重複、自分の表示が一つであること、回転時の表示維持、首位の案内を検査。
- 最初の小型画面テストはリサイズ完了前のタップで失敗。既存テストと同じCanvas幅の待機を加えて再検証し成功。
- [320px幅](karma-league-compact.png) / [横向き](karma-league-landscape.png) の実スクショを目視確認。

実機Safari / Android、外部Portal、mainへの統合・公開は未実施。
