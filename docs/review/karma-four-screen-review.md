# Karma Quest 4画面比較 — 2026-09-18

正式モック `karma-visual-mock.jpg` と、320×568のブラウザで撮影したキャンバス（314×558）を比較した。
比較画像: [4画面比較](karma-four-screen-comparison.png)。上段は正式モックの画面部分、下段は実装。画像の縦横比は保持している。

## 今回の修正

- 横画面ホームは人物・王都背景を左、依頼と保存済み実績・出発ボタンを右に分離。[ホーム](karma-compact-home-landscape.png)。横画面年代記は人物・能力値を左、最新の選択と直前の記録・再出発を右へ配置。[年代記](karma-compact-chronicle-landscape.png)。縦横で同じ実データを参照する。横ホームは出発中心の構成で、縦ホームの情報ナビは未配置。
- ホームの依頼を実際の抽選結果に接続。出発した1年目にはその依頼を引き継ぎ、次の旅用の依頼は別途抽選する。固定レベル・通貨は表示せず、保存済みの累計評価・最高到達年を表示する。
- 選択画面の依頼者は全身を縮める配置から、270×270の領域に頭・組んだ手を収める配置へ変更。縦横同率で拡大し、ローブ下部をトリミングした。左下の主人公と顔が重ならず、本文下端から6px、ボタン上端から13pxの間隔を確保。背景の暗さも軽減した。
- 横画面の選択画面を、左側の対話イラストと右側の羊皮紙・選択ボタンに再構成。縦画面と同じ文字・金枠・青赤ボタンを使い、画像の比率を維持。[横画面の確認画像](karma-compact-choice-landscape.png)。本文は24設計px、ボタンは80設計px高。800×360と932×430で回転後の承諾・拒否が一度だけ反映されることを検証する。
- ホームの通知と左ナビを21設計pxに拡大。左ナビの枠を70設計px、タップ幅を76設計pxに広げた。「メニュー」は遷移先に合わせて「案内」と表記。上部補足を18設計px、下部ナビを19設計pxへ拡大し、通知と依頼カードの境界も分離した。
- 選択ボタンの主ラベルを26設計pxへ拡大。小型スマホで約18 CSS pxになる。補足は19設計px。
- 結果画面の絵を独立した領域に収め、人物の顔を下のカードで切らない構図にした。本文と派閥表示を21設計pxへ拡大。情報カードの上端を上げ、拡大した文字と行の間隔を確保した。
- 年代記の本文・記録件数・能力名は21設計px、能力値は22設計pxへ拡大。カードの高さと画像幅を調整し、見出しと本文が重ならないようにした。
- 再出発ボタンを80設計pxへ拡大。320px幅で約56 CSS pxの高さを確保する。
- 全8依頼の承諾・拒否について、縦横の結果本文と引用、縦の年代記見出しと本文の領域を実ブラウザで確認するテストを追加。縦の主要本文・能力名は14 CSS px以上を検査する。

## 残る差

- ホームの通知・ナビの可読性と実データへの接続は改善済み。依頼者の画像は全派閥で老人を共用しており、内容に合わせた素材の使い分けは残る。
- 選択画面はユーザー指定の左下バストアップを維持。依頼者の大きさと背景の明るさを調整済みだが、モックの人物同士の視線や会話背景そのものとの差は残る。
- 魔術師の結果・年代記には専用の研究室イラストを追加済み。[素材と生成プロンプト](karma-mage-study-asset.md)。他派閥は中立的な王都背景とし、食料配布は食料依頼の承諾時だけに限定。戦士・商人・荒くれ者の専用場面は未作成。
- 年代記の情報と横画面構成は改善済み。モックの本の見出し装飾や出来事ごとの画像の使い分けは未対応。
- 全体の金枠・ボタンの質感にもモックとの差がある。比較画像とテスト成功をもって再現完了とは判定しない。

## 再生成

`games/karma-quest` で `npm run dev -- --port 15177` を起動し、リポジトリ直下で `node scripts/review-karma-screens.mjs` を実行する。
スクリーンショットは実行時のゲームから撮影する。比較用データは魔石の依頼を1件承諾した状態で固定している。
