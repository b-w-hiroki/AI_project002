# 4画面のモック比較・金具の調整

ホーム・会話・結果・年代記を写真5のモックと比較。今回は枠の単調さとボタンの平面的な色面を調整した。人物サイズや情報配置の全面変更ではない。

- 全画面共通の金具に細い葉の彫り模様を追加。装飾は外周に収める。
- 青赤のボタンを左右対称の縦グラデーションに変更。上辺の反射と下辺の陰影で立体感を加える。操作領域・文字サイズ・ラベルは維持。
- 年代記の本を幅56pxにし、表紙・重ねたページ・背面円を描く。
- イラスト原素材・寸法・切り抜きは変更していない。画像の追加通信もない。
