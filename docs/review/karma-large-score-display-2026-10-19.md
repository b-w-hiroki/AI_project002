# Karma Quest 大きい評価点の表示

## 改善と実装

1. ホーム・縦横リーグの評価点を共通関数で表示。1万未満はそのまま、以降は万・億・兆を使う。
2. 小数1桁で切り捨て、未獲得の点数を切り上げ表示しない。保存値は省略しない。
3. 到達年ボーナスを含むリーグ評価が安全な整数の上限を超えないよう飽和する。

通常点数・既存のデザイン・文字サイズは維持。新規画像素材なし。

## 検証

- 修正前の320pxホームで16桁の点数が枠幅いっぱいに詰まる状態を撮影し、新しい表示のE2Eが失敗することを確認。
- typecheck / lint / 単体109件 / build成功。
- Chromium関連3件 / WebKit同3件成功。通常のリーグ、最大値付近の列間・行間・見出しの範囲、縦横回転、報酬後の表示を確認。
- 保存値が省略表記に変換されていないこともE2Eで確認。
- [320pxホーム](karma-large-score-home.png)、[320pxリーグ](karma-large-score-league.png)、[横向きリーグ](karma-large-score-landscape.png)を目視確認。
