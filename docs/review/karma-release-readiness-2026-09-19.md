# Karma Quest 残タスク対応 — 2026-09-19

この後の追加対応で初回画像は約16.6 MBへ削減済み。[段階読み込みと最終確認](karma-deferred-loading-review.md) を最新状況として参照。以下は変更前後の経緯を残した記録。

対象はKarma Questのモック寄せとスマホUIの仕上げ。他5作品、新規ゲーム機能、マージ・公開は含まない。

## 対応内容

- 持ち物・ガチャ・ショップは、押す前から「未提供」と分かる表示を縦横ホームに追加。説明モーダルは維持。
- 既存PNG 13枚を可逆WebPへ変更。復号後RGBA完全一致を全13枚で検証し、元PNGは保存。変換対象を `scripts/prepare-karma-assets.py` に追加。
- 置き換え済みの旧戦士結果絵を起動時の読み込みから除外。
- 同一ページで12年間の旅を3回繰り返す検査と、読み込み量の測定スクリプトを追加。結果は下記の生データに保存。
