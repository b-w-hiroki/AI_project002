# Potion Workshop レイアウト最終判断

更新: 2026-09-22

## 結論

全面再配置は行わず、現行のカードUI + レスポンシブレイアウトを維持する。

## 理由

- 調合エリア、設備一覧、注文、転生の4系統がすでに視覚的に分離されている。
- 縦画面では調合を主役にし、横画面では設備/管理情報を広く見せる役割分担が成立している。
- PR #110 の調合バースト、PR #117 の街選択、PR #131 の8設備個別シルエットにより、全面レイアウト変更をしなくても成長感を追加できている。
- 全面再配置をすると、既存のE2E座標・カード階層・モバイルレイアウトを広範囲に再調整する必要があり、得られる改善に対して回帰リスクが高い。

## 維持する骨格

- 左/中央: 錬金術師 + 大釜 + 手動調合
- 設備: カード/行ベースで購入・所持数・生産量を比較
- 管理: TAP強化 / 放置 / 転生
- 注文: モーダル
- 転生先: 2択モーダル
- 街差分: 背景グロー、需要、注文報酬で表現

## 今後の改善方針

全面再配置ではなく、以下の局所改善だけを行う。

1. 設備カードの個別シルエットと購入可否のコントラストを維持。
2. 転生可能時のカード/グローを最優先CTAとして扱う。
3. 街選択モーダルで需要設備と評判倍率を必ず表示。
4. 小型端末では情報を削るのではなく、優先度の低い補助文だけ短縮する。
5. 新機能追加時も新しい常設パネルを増やさず、注文/転生と同様にモーダルを優先する。

## Done条件

- 現行カードUIを正式なベースラインとして扱う。
- 今後のPotion Workshop改修で「全面再配置」を前提タスクにしない。
- レイアウト変更が必要になった場合は、実機QAまたはユーザビリティ上の具体的な問題を根拠に別Issue化する。
