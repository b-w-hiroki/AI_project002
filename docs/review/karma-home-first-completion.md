# Karma Quest ホーム先行読み込み・完了記録

2026-09-19。今回対象のモック寄せ・スマホUI・読み込み改善について、ローカルで可能な実装と検証を完了。実スマホの確認は未完了であり、全ゲームの機能実装や公開完了を意味しない。

## 実装

- 初回はホームの背景と必要な人物・アイコンだけを読み込む。会話用素材は出発時、結果絵は選択時に取得する。準備前に非表示画面を組み立てない。
- 出発準備中も縦横レイアウトと状態表示を維持する。失敗時はホームに留まり、再操作で再試行する。連打では二重に進行しない。
- 配信用WebP32枚を追加。原素材は保存し、寸法とアルファ値を変えずに再圧縮。不透明部分のRGB PSNRは36dB以上。小さな画像は再圧縮で増える場合に原本を採用。全配信画像の合計は11,121,530 bytes。
- 文字・ボタン・人物の配置は維持。圧縮は非可逆なので画素同一とはしない。再生成スクリプトと画像別の画質・容量記録も保存。
