# モック寄せタスクの対応記録

対象はホーム・会話・結果・年代記。モック写真5と最小幅320pxの実装を並べ、以下を対応した。モックの完全一致を意味しない。

| タスク | 対応 |
| --- | --- |
| 構図の設計 | `docs/design/karma-mock-alignment-2026-09-20.md` に座標・維持条件・判定方法を保存 |
| 会話の紙面 | 紺帯を外して紙上の見出しへ。縦紙面を14px短縮、依頼者側へ尾を追加 |
| 人物の距離感 | 全4派閥を比較。左下バストアップと顔の独立領域を維持。無理な拡大や引き延ばしはしない |
| ホーム | 背面主人公を約3%拡大し、少し左上へ。既存の文字・ナビ領域を保持 |
| 結果の場面性 | 魔石・護衛・酒代の承諾3枚を新規生成し接続。肖像から、支援による出来事を描いた絵へ変更。残る13結果は一覧で点検して維持 |
| 年代記 | 出来事の挿絵を124→148px幅へ拡大。本文を左揃えにし、出来事から能力へ読む既存順を維持 |
| ボタンの紋章 | 青い承諾へ天秤、赤い見送りへ王冠。主ラベルを右へ12px移動し、文字と紋章の領域を分離 |
| 文字 | 本文21〜24px・主要操作26px・補足19pxを維持。横会話の見出しも紙上の暗色文字へ統一 |
| 素材の統一 | 新規3枚は象牙色の王都、青い旗、暖かい光で統一。PNG原本と旧版を保存。生成指示は `docs/art-sources/karma/story-scenes-v2-prompts.md` |
| 仕上げと検証 | 4画面・全16結果・4派閥・横画面の画像を更新。細い金枠と紙へのフェードを維持 |

[4画面比較](karma-four-screen-comparison.png) / [承諾8場面](karma-outcomes-accept.png) / [見送り8場面](karma-outcomes-decline.png) / [会話4派閥](karma-dialogue-patterns.png)

新素材は1536×1024。配信用WebPは魔石478,468 bytes・護衛481,826 bytes・酒代353,178 bytes。寸法・透明度維持、不透明RGB PSNR36dB以上。選択時に取得するため初回ホームへの追加画像リクエストはない。

実iPhoneのノッチ・音・発熱確認はWi-Fi接続が可能になるまで保留。筆致と構図はモックに寄せた改善であり、完全再現・実機合格とは判定しない。

検証: 単体39件、typecheck・lint・build成功。E2E全27件を実行し、操作・16結果の文字分離・回転・失敗再試行など23件成功。残る4件は今回のホーム・会話・結果・年代記の意図した画像差分であり、目視後に基準画像を更新して通常比較でも4件成功。画面設計の定数にあった古いホーム幅・年代記の操作領域も実際の描画座標へ修正し、領域検査を再実行した。
